# 历史部署脚本

本目录包含历史遗留的特定场景部署脚本，仅在特殊情况下使用。

## 📋 脚本说明

### 数据绑定部署
- `deploy-71-data-bindmounts.sh` - 71服务器数据绑定挂载部署
  - 用于处理 Docker 容器的持久化数据挂载
  - 包含 attachments 目录的绑定挂载配置
  - 解决容器重启后数据丢失问题

## 🚀 使用方法

```bash
# 部署数据绑定挂载配置
./scripts/legacy-deploy/deploy-71-data-bindmounts.sh
```

## ⚠️ 重要提示

1. **优先使用核心部署脚本**: `../deploy.sh --target=71 --mode=docker`
2. 本脚本仅在以下情况使用：
   - 需要特殊的数据挂载配置
   - 核心部署脚本无法满足需求
   - 处理历史遗留问题

## 🔄 迁移建议

如果您经常使用这些脚本，建议：
1. 将功能集成到核心部署脚本 `../deploy.sh`
2. 或创建新的专用部署选项
3. 避免长期依赖历史脚本
